# 최애시 타이머

생일의 월과 일을 시각으로 바꿔 매일 2번, 5분 전과 정각에 알려 주는 Chrome 확장 프로그램입니다.

## 구현된 기능

- 최애 최대 10명 등록, 수정, 삭제 및 개별 알림 켜기/끄기
- 생일 기반 최애시 자동 계산 (`8월 1일 → 08:01 / 20:01`)
- 다음 최애시와 초 단위 카운트다운
- 같은 시각의 여러 최애를 하나의 알림으로 통합
- `chrome.alarms` 기반 5분 전/정각 알림과 브라우저 재시작 시 재예약
- 사진을 256×256 WebP로 리사이즈해 IndexedDB에 로컬 저장
- 최애 정보는 `chrome.storage.local`에 저장

## 실행

```powershell
npm.cmd install
npm.cmd run dev
```

개발 빌드는 `.output/chrome-mv3-dev`에 생성됩니다. Chrome의 `chrome://extensions`에서 개발자 모드를 켠 뒤 **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더를 선택하세요.

프로덕션 빌드:

```powershell
npm.cmd run typecheck
npm.cmd run build
```

결과물은 `.output/chrome-mv3`에 생성됩니다.

## 추가로 고려할 사항

- Chrome 알림은 운영체제 절전, 집중 모드, Chrome 종료 상태에 따라 늦게 표시될 수 있습니다.
- PC의 현지 시간대를 사용합니다. 실행 중 시간대가 바뀐 경우 Chrome 재시작 또는 데이터 변경 시 다음 알림이 다시 계산됩니다.
- 확장 프로그램 삭제 시 로컬 데이터와 사진도 삭제됩니다. 다음 버전에서는 JSON 백업/복원 기능이 유용합니다.
- 사진과 최애 정보가 서로 다른 저장소에 있으므로, 대규모 마이그레이션이나 복원 기능을 추가할 때 일관성 처리가 필요합니다.
- Web Store 배포 전에는 PNG 형식의 16/32/48/128px 아이콘, 개인정보 처리 안내, 알림 권한 사용 사유, 실제 OS별 알림 시험이 필요합니다.
- 자동화 테스트는 시간 계산(특히 자정 경계), 중복 통합, 재예약 로직을 가짜 시계로 검증하는 방식이 적합합니다.
